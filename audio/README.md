# 拼音音频素材

单音节 MP3 音频来自 [agj/mp3-chinese-pinyin-sound](https://github.com/agj/mp3-chinese-pinyin-sound)。
原仓库授权：**Unlicense**（公有领域，任意使用无需归属）。

文件命名规则：`<pinyin>[<tone>].mp3`
- `ba1.mp3` = bā
- `ba4.mp3` = bà
- `luu3.mp3` = lǚ（`ü` 用 `uu` 表示）

## 缺失音节

音库标注的以下音节没有对应 MP3，代码里已用近似音替代：
- `o1`（喔）→ 用 `wo1`（我）近似
- `eng1`（鞥）→ 用 `weng1`（翁）近似
- 少数轻声（如 `ma5`）文件为空
